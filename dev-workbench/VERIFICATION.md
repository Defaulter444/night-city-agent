# Проверка поставки — 29.09.2026

## Выполнено в контейнере подготовки

- Node.js 22.16.0: `npm test` — **16/16** тестов пройдено.
- `node --check` для всех `.mjs` — синтаксических ошибок нет.
- JSON-конфигурации — разобраны JSON-парсером без ошибок.
- HTTP preview server — запущен и проверен через локальный HTTP-клиент; пути к `.tools`, `.env`, конфигурации Codex и чужим файлам не выдаются.
- Chromium 144.0.7559.96 / Python Playwright — **18/18 проверок компонентов** для ширины 1440 и 390 px. Проверены отображение, отсутствие горизонтального переполнения, пустой ввод, вывод текста без интерпретации HTML, раскрытие узла, счётчик событий, reduced motion, очистка только тестовых данных и отсутствие необработанных ошибок.

## Существенное ограничение браузерного прогона

Навигация Chromium к локальному HTTP-серверу заблокирована политикой среды (`ERR_BLOCKED_BY_ADMINISTRATOR`). Политика не изменялась. Компоненты проверены в памяти через `page.set_content`, с явной тестовой заменой localStorage. Это **не** полноценный E2E-тест сетевой загрузки, настоящего localStorage или сохранения после перезагрузки.

Скриншоты `desktop.png`, `narrow.png` и машиночитаемый отчёт приложены к ZIP в `verification/`. Скриншоты показывают автономный стенд, не игровой Foundry.

- Создание/запуск реального GitHub Codespace и проверка Dev Container.

- Установка сервера Foundry, лицензии, системы, миров; тесты мастера и игрока.

## После создания Codespace

`npm run doctor` → `npm run check` → вход в выбранный CLI → тест MCP → интеграционные проверки в отдельном Foundry v12 по FOUNDRY-CHECKLIST.md.

Первая установка формирует lockfile. Список фактически установленных версий нужно сохранить после успешной установки. В этой поставке не утверждается, что все инструменты уже установлены и полностью интегрированы.
