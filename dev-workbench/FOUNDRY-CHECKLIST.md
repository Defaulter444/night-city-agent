# Проверка в настоящем Foundry — пока НЕ выполнена

Сам Foundry, ключ лицензии, система и миры в комплект не включены.
Используй отдельный тестовый каталог User Data и отдельный мир. Не открывай один мир одновременно двумя процессами сервера.

Перед интеграцией запиши `game.version`, `game.system.id`, `game.system.version`, версии модулей и браузера.
Agent baseline, прочитанный 29.09.2026: 0.16.0, minimum 12, verified 12.331; зависимости socketlib и Simple Calendar 2.4.18.
NET baseline: 1.9.0, minimum 12, verified 12.343. Это записи из манифестов, не проверка установленной игры.

Проверки при переносе нового интерфейса:
- GM и игрок, оба клиента одновременно; игроку не показываются скрытые данные GM.
- Сообщение/действие выполняется ровно один раз после пяти закрытий и открытий окна.
- Старые контакты, номера, переписки и NET-архитектуры читаются без изменений.
- Сохранение после F5 и перезапуска тестового сервера; обновление синхронизируется между клиентами.
- Длинная русская строка, пустой список, ошибка доступа, отсутствие выбранного токена.
- Анимации off/moderate/cinematic и системный reduced motion.
- Тяжёлая сцена; эффекты останавливаются после закрытия; нет растущих таймеров и обработчиков.
- Итоговый release ZIP соответствует module.json и исходникам; релиз не создавать автоматически.

Sequencer нужен только для эффектов Canvas, а не для кнопок HTML. Устанавливай версию, чей диапазон совместимости включает v12. Его отсутствие не должно ломать обычный интерфейс.
