# Foundry v12 / Cyberpunk RED workbench

Отвечай по-русски. Эта папка — инструменты и автономная демонстрация, не код установленного модуля.

## Неприкосновенные границы
- Цель — Foundry VTT v12. Точную сборку и версию cyberpunk-red-core выясняй из тестового экземпляра. Не подставляй API v13/v14.
- Не изменяй телефоны НПС, UUID, переписки, NET-архитектуры, schema/storage/settings ради редизайна.
- Изменение схемы данных — отдельная согласованная миграция и тест на копии старых данных.
- Никогда не работай с боевым миром. Не загружай лицензию Foundry, ключи API, токены и browser storage в GitHub.
- Не делай push в main/master, merge, release, force-push и покупку подписок без отдельного указания пользователя.
- Не отключай approvals и sandbox. Не публикуй MCP/CDP/Foundry-порты в интернет.

## Процесс
1. Прочитай инструкции внутри целевого репозитория и module.json. Запиши текущую ветку и SHA.
2. Одна ограниченная задача на одну ветку/worktree. Два агента не пишут в один worktree одновременно.
3. Прототипируй компоненты отдельно. Базовая анимация — CSS/WAAPI; Anime.js допустим для сложной последовательности.
4. Сохраняй живые элементы HTML, текст через textContent; не подменяй интерфейс картинкой.
5. Сохраняй режим «без анимаций» и prefers-reduced-motion; очищай обработчики и таймеры при закрытии.
6. Запусти проверки. Отдельно укажи реально выполненное и недоступное.
7. Демо-проверка и screenshot НЕ доказывают работу в Foundry. Для интеграции нужны GM/player, перезагрузка, права, сохранение и отсутствие двойных обработчиков.

## Команды (из dev-workbench)
- npm run doctor — установленность инструментов, НЕ проверка авторизации.
- npm run preview:offline — независимый демостенд без npm-зависимостей.
- npm run check — ESLint, Node tests, Vitest, Vite build, Playwright.
- npm run audit:module -- ../ — статический аудит манифеста родительского модуля.
- npm run repos — отдельные копии выбранных публичных репозиториев; существующие каталоги не изменяются.
- npm run codex / npm run gemini / npm run claude — CLI; вход выполняет пользователь.

Лимиты разных сервисов не объединяются и не сбрасываются установкой среды. Не запускай платный API, бесконечные циклы агента или фоновую массовую обработку без задания.
