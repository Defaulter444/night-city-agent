# Isolated audit changes

Agent ledger operations are serialized on the GM. Transfers validate recipient and permissions before debiting; rejected delivery refunds the debit. Receipts remain available while old chat cards can be used. Includes regression tests for invalid recipients, concurrent transfers, old receipts and ownership.

Tested against the installed Cyberpunk RED v0.92.4 / Foundry 12.331 installation in a separate data directory. This is an audit branch, not a published release. Some existing packs require Foundry 12.343; complete translation and all module combinations are not certified.
