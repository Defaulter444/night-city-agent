# Конференции и личные заметки · 0.13.0

Для Foundry VTT 12. Создание и отправка данных требуют подключённого мастера.
Обновите страницу у мастера и всех игроков после установки модуля.

## Контакты

«+» в списке сообщений открывает добавление контакта. Номер виден на тёмном фоне.
Можно ввести `12345678`, `1234 5678` или `1234-5678`: сохранится `1234-5678`.
Имя необязательно: контакт сохранится под номером, даже если ещё нет переписки.
Добавить можно только существующее устройство.

## Конференции

1. Выберите свой Агент. Мастер может выбрать устройство НПС.
2. Откройте кнопку с несколькими людьми рядом с «Файлы».
3. Нажмите «+», укажите название и участников. При создании ваш номер добавляется автоматически; всего допустимо 2–32 номера.
4. Выберите конференцию слева. Отправляйте текст, картинки или файлы. Enter отправляет, Shift+Enter переносит строку.

Автор каждого сообщения подписан именем из вашей книги и номером. Незнакомый
контакт отображается по номеру. Черновики и отметки прочтения сохраняются отдельно
для каждого устройства. Мастер может переключать участвующие устройства в шапке.

Меню участников позволяет создателю конференции и мастеру изменить название и
состав. Новый участник получает всю историю. Исключённый участник теряет доступ
к конференции и её файлам, если у него нет другого доступа к этим файлам
(например, он ранее сохранил их в свой Агент). Любой участник может выйти.
Передача устройства передаёт новому владельцу доступ к его конференциям.

Общие чаты хранятся отдельно от личных переписок. Они входят в состояние Агента,
его экспорт и защищённое хранилище, если оно включено. Мастер видит все конференции.

## Личные заметки

В меню «…» Агента выберите **«Создать заметку»**, укажите название и текст.
Первая заметка создаёт обычный журнал Foundry **«Заметки Агента — имя игрока»**;
каждая следующая добавляет страницу в конец этого журнала. После сохранения
открывается новая страница. **«Личный журнал»** открывает существующий журнал.
В нём можно редактировать страницы обычными средствами Foundry.

Журнал доступен владельцу и мастерам. Другие игроки не получают доступа по умолчанию.
Права на создание журналов в настройках игроков выдавать не требуется: запрос
проверяет и выполняет мастер. Одновременные сохранения не создают дубликаты журнала.
Если сохранение не удалось, текст остаётся в форме.

У игрока один журнал для всех его Агентов; при передаче устройства записи остаются
у прежнего игрока. Мастер, работающий с Агентом игрока, создаёт заметку в журнале
этого игрока. Заметки устройства НПС сохраняются в журнале владельца-мастера,
а у устройства без владельца — в журнале мастера, создавшего заметку.

**Заметки сохраняются в базе журналов мира Foundry.** Делайте резервную копию мира:
экспорт/ключ хранилища Агента не содержит страницы этих журналов и не шифрует их.

## Уведомления для мастера

Личное сообщение игрока устройству без владельца или устройству мастера считается
входящим для НПС. Все подключённые мастера видят уведомление с отправителем и
адресатом. Это работает для текста, картинок, файлов и карточек контактов.
В конференции с НПС уведомление также показывает название группы.

Для открытой переписки звук не запускается; для непрочитанной используются
существующие настройки рингтона. Собственные сообщения мастера не создают
уведомлений «игрок написал НПС».

## Существующая миссия

Обновление не пересоздаёт устройства, контакты, личные переписки или файлы.
Конференции создаются по запросу. Личный журнал появляется при первой заметке.
Перед обновлением сохраняйте обычную резервную копию мира; при включённой защите
сохраните также действующий ключ восстановления Агента.
