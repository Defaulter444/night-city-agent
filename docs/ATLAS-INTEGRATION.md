# Agent ↔ Atlas: необязательная связь

Версия Агента: 0.17.3. Модуль Atlas: `night-city-2045-atlas`.

У задания или места Агента может быть строковое поле `atlasLocationId`: 1–128 ASCII-символов `a-z`, `A-Z`, `0-9`, `_`, `-`. Служебные ключи `__proto__`, `prototype`, `constructor` отклоняются. Пустое поле удаляет связь; старые клиенты, не передающие поле при редактировании, сохраняют существующую связь. Это внешний идентификатор, а не URL или координаты. Совпадение с текущим каталогом проверяет Atlas при открытии.

Редактор получает варианты через необязательный `Atlas.api.listLocations()`. При отсутствии API остаётся поле ID. Кнопка «В Atlas» требует активный модуль, синхронный `api.canOpen() === true` и функцию `api.openLocation(id)`; доступ проверяется повторно при нажатии. Установка этой версии Агента сама по себе не открывает Atlas игрокам.

## API Агента

```js
const agent = game.modules.get("night-city-agent").api;
const jobs = await agent.jobsForLocation(atlasLocationId);
await agent.openJob(jobs[0].id);
await agent.draftJobForLocation({id: atlasLocationId, name: "Посмертие"});
```

- `jobsForLocation(id): Promise<Array<{id,title,status}>>` — только читаемые текущим пользователем задания с точным совпадением внешнего ID. Пустой ID возвращает `[]`. Нет текста, награды, получателей, этапов или изображения. Включены архивные задания; статус позволяет вызывающей стороне выбрать нужную группу.
- `openJob(id): Promise<AgentApp>` — повторная проверка доступа, выбор доступного устройства, раздел «Задания», правильная группа активных/архивных заданий, очистка поиска и фокус карточки. Недоступный ID отклоняется без открытия окна.
- `draftJobForLocation({id,name}): Promise<string|null|undefined>` — только GM. Открывает существующий редактор с названием «Работа: …» и внешним ID; изначально не опубликовано. Нужен хотя бы один Агент. После сохранения возвращает ID, после отмены — `null`; уже занятый редактор может вернуть `undefined`. До Save запись задания отсутствует.

Два читающих метода используют обычное обновление разрешённой проекции Агента. Смена текущего пользователя или закрытие хранилища во время обновления отменяет действие. Интеграция не добавляет socket-handler, не отправляет полное состояние GM и не обходит серверные права `osOperation`.

Atlas может вызывать `openAgent({tab:"jobs"})` или `openAgent({tab:"map"})` для общего перехода. Другие модули не должны менять внутренний DOM или состояние Агента.
