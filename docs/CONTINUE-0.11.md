# Откуда продолжить после локального обновления 0.11

Рабочая ветка: `agent-documents-2026-09-14`. Основа — локальный аудит Агента `c840bbe`, включая исправления очереди состояния, прав, кошелька и экстренных служб. Новое обновление добавляет интерфейс, документы/терминалы и защиту. Публикация этой версии на GitHub ещё не выполнялась.

1. Получить впечатления мастера от локального интерфейса и текущей миссии. Установка не включает шифрование автоматически: его включает мастер в своём основном браузере после сохранения файла восстановления.
2. Следующее функциональное изменение — согласовать и реализовать мост с `cpr-netrunning`: выдача уже полученного в NET-архитектуре файла в документы Агента. Не добавлять второй расчёт Интерфейса, NET-действий, дистанции или урона.
3. Дополнительно можно расширить управление носителями: перенос ссылок при создании новой копии Item с другим UUID, ссылки на документы из результатов таблиц. Сейчас поддерживаются текстовые документы и конкретные разрешённые носители.
4. При разрешённой публикации проверить diff всей ветки относительно GitHub, включить прежние локальные исправления, собрать `node tools/build-changelog.mjs` и `node tools/make-release.mjs`, проверить ZIP, затем создать релиз 0.11.0 с ZIP и module.json. Не выкладывать копии миров, ключи, тестовые пользовательские данные или локальные журналы.

Проверки: `node --test test/*.test.mjs`. Нативный проход выполнен в Foundry 12.331 / Cyberpunk RED 0.92.4 от мастера и обычного игрока, отдельно от рабочих миров. Данные реальных миров проверялись только в копиях.
