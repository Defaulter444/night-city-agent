# Агент OS — локальная сборка 0.15.0-local.1

Новый интерфейс установлен поверх существующего Агента. На GitHub эта сборка не опубликована. После обновления перезапустите Foundry и обновите страницы игроков.

Внизу окна находятся десять разделов. В узком окне они переходят в два ряда, содержимое — в одну колонку. Окно можно растягивать обычным способом. Настройка «Компактный корпус» убирает часть оформления.

## Что доступно

| Раздел | Возможности |
| --- | --- |
| Главная | Панорама города, время, быстрые контакты, последние сообщения, баланс, текущая работа, заметки, напоминания и городская лента. |
| Контакты | Поиск по имени, номеру и заметкам; портреты, категории, избранное; переход в переписку, вызов и перевод. Личные пометки видны владельцу и мастеру. |
| Сообщения | Существующая переписка с портретами, картинками, файлами, поиском, черновиками и закреплениями. Конференции доступны по кнопке с участниками в шапке. Рассылка — в контактах или меню. |
| Карта | Изображение карты кампании, масштабирование, категории мест, метки, описание, контакт и отправка места сообщением. |
| Кошелёк | Реальный баланс и история из листа персонажа, переводы, запросы участникам на разделение счёта, напоминания о расходах. |
| Задания | Личные дела и задания от мастера, награда, заказчик, срок, статусы, этапы с флажками, ссылка на место, отправка текста задания. |
| Файлы | Общий рабочий экран текста и изображений; создание и редактирование, передача, личные папки, метки, избранное, экспорт JSON, заметки в отдельном журнале. Терминалы и носители доступны отсюда. |
| Data Pool | Новости, слухи и объявления, которые публикует мастер; изображения, поиск, закладки, отправка текстом и сохранение в файл. |
| Вызовы | Игровой вызов одному или нескольким собеседникам: приглашение, принятие или отказ, портреты, таймер, добавление участников и история. |
| Настройки | Позывной, роль, описание, портрет, игровой статус доступности; компактное оформление, уменьшение эффектов, рингтон, доступ к копиям данных, службам и предметам связанного персонажа. |

## Первый запуск

1. Откройте «Агент» обычной кнопкой Foundry. Существующие номера и контакты доступны сразу.
2. В «Настройках» заполните профиль своего устройства. Портрет можно загрузить с компьютера или указать путь к изображению Foundry. Загружаемый портрет автоматически уменьшается и сохраняется в WebP. «Карточка» контакта позволяет задать личный вариант портрета, категорию и заметку.
3. Мастер открывает «Карта → Карта и погода» и выбирает изображение карты своей кампании. Положение места задаётся в процентах по горизонтали и вертикали. Панорама на главной — оформление; она не заменяет игровую карту.
4. При создании места, задания или публикации мастер отмечает «Опубликовать для игроков» и выбирает номера либо доступ для всех. Без публикации запись остаётся черновиком мастера.
5. В кошельке используется персонаж, назначенный владельцу устройства в Foundry. Если у игрока несколько листов, назначьте нужный лист или выделите принадлежащий ему токен. Владелец устройства не меняется при редактировании профиля.

## Уточнения по работе

- Вызов — сценический интерфейс для отыгрыша. Аудио и видео не передаются, запись микрофона не выполняется. Разговаривайте через привычный голосовой чат. Текстовые конференции продолжают работать отдельно.
- На карте нет GPS, автоматических маршрутов, расстояний по улицам и быстрого перемещения токенов. Карту и сведения о местах задаёт мастер.
- Data Pool здесь — внутриигровая лента кампании. Она не загружает реальные новости и не ищет сведения в Интернете.
- Баланс связан с листом Cyberpunk RED. Отдельные банковские счета и тайники не создаются. «Разделить оплату» отправляет просьбу о переводе; автоматического списания нет. Награда за задание также не начисляется автоматически. Для переводов на номер НПС используйте прежнее окно перевода с явным выбором листов.
- Срок задания — свободная игровая подпись. Напоминания отдельно используют реальные минуты либо игровое время Foundry, которое продвигает мастер. Проверка выполняется каждые 15 секунд, пока клиент подключён; при следующем входе просроченное незавершённое напоминание может появиться снова.
- Настройка статуса профиля — игровой статус, заданный владельцем. Это не проверка присутствия игрока за компьютером.
- Новость с загруженной картинкой сохраняет её в файл. Для картинки по внешней ссылке или пути сохраняется ссылка в тексте файла.
- «Отправить задание/место/новость» отправляет текст и использует обычные ограничения сообщений Агента. Это не выдаёт получателю доступ к самой закрытой записи.
- Обзор имплантов и снаряжения открывает существующие листы предметов. Он не добавляет дистанционное управление устройствами и не меняет правила имплантов.

## Сохранность кампании

Обновление не меняет номера, адресные книги, переписку, позиции прочтения, идентификаторы файлов и конференций. Новые сведения хранятся дополнительно в `state.os`. Существующие файлы используют прежние права автора, заметки — прежние личные журналы. Защищённое хранилище и резервные копии включают новые сведения.

Игрок получает только доступные ему задания, места и публикации. Чужие пометки контактов, напоминания, папки и метки файлов ему не передаются. Профиль виден знакомым контактам и участникам вызова. Мастер сохраняет доступ к информации кампании.

Тестовые персонажи, миссии, новости и портрет из проверки не включены в установленную сборку и не добавлены в рабочие миры. В модуль включена только отдельная панорама оформления. Резервная копия заменённых файлов создана рядом с материалами локальной сборки. При откате следует вернуть эти файлы при выключенном Foundry; данные миров для смены интерфейса заменять не требуется.

## Где продолжать разработку

После проверки этой локальной сборки в реальной группе можно отдельно планировать голосовую связь, аудиовложения, календарную сетку с интеграцией календаря кампании и маршруты по карте. Они требуют самостоятельных сценариев и настроек; декоративные кнопки для них не добавлены.
