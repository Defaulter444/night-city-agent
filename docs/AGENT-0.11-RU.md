# Агент 0.11 — локальное обновление

Обновление расширяет существующий Агент. Номера устройств, владельцы, книги контактов, сообщения и отметки прочтения продолжают использовать прежние идентификаторы. Установка модуля сама по себе не переписывает данные миров.

## Переписка

Слева — контакты и поиск по имени, номеру, меткам и тексту сообщений. Справа — разговор. Кнопка закрепления в заголовке оставляет только закреплённые сообщения. Закрепления и метки относятся к вашему устройству.

В меню контакта находятся его имя, метки, обмен карточкой контакта и перевод эдди. В общем меню — рингтон, экстренные службы, руководство и резервные копии. Старые функции сохранены.

Черновик сохраняется после паузы в наборе и при закрытии/переключении контакта. Для сохранения на сервере нужен подключённый мастер. При ошибке сохранения закрытие окна отменяется, чтобы набранный текст оставался доступен. Сообщения отправляются Enter; Shift+Enter добавляет строку.

## Файлы и терминалы

«Файлы» открывает отдельное окно. Документ можно создать, прочитать, сохранить в свой Агент, отправить контакту или записать на доступный носитель. Содержимое показывается как обычный текст, без исполнения HTML и скриптов. Редактировать общий документ может мастер; ссылка в переписке продолжает указывать на тот же документ.

Носитель должен быть на листе, которым владеет пользователь: переносимый/экипированный чип памяти либо установленный носитель киберимпланта. Для переименованных предметов поддерживаются исходное имя Babele и явный флаг `flags.night-city-agent.dataCarrier`. На предмет записываются ссылки на документы. Доступ по ссылке проверяется мастером. Перенос предмета между листами путём удаления и создания новой копии требует повторной выдачи документа; автоматическая миграция UUID предметов не заявляется.

Мастер создаёт переносные терминалы или терминалы определённой сцены, выбирает пользователей, добавляет письма и файлы, публикует их отдельно. Игрок видит разрешённые терминалы через кнопку монитора на панели токенов. Копирование терминала сохраняет структуру и ссылки на готовые документы; результат случайной таблицы в копии создаётся заново.

Для таблицы первый доступ сохраняет один результат для всей группы. Повторные и одновременные открытия не перебрасывают содержимое. Режим «Глазами игрока» скрывает неопубликованное и не запускает таблицу. Результаты таблиц преобразуются в текст; встроенные ссылки на другие документы автоматически не импортируются.

Терминал можно открыть выбранному подключённому игроку. Проверки пользователей и сцены продолжают действовать. Привязка к выбранному тайлу добавляет кнопку «Терминал» в настройках тайла; основной доступ игроков не требует права редактировать тайлы.

Отложенные сообщения NPC используют реальное время либо часы мира Foundry. Доставка выполняется при подключённом основном мастере; после пропущенного срока сообщение доставляется при следующей проверке. Одинаковое сообщение расписания не создаётся повторно. Смена мира не запускает внешнюю задачу или таймер Windows.

## Защита и восстановление

Обновление запускается в совместимом режиме: прежняя миссия доступна сразу. Адресная доставка использует получателей на сервере Foundry 12, а не фильтрацию общей рассылки в браузерах. Само по себе это не скрывает прежнюю world setting от технически подготовленного игрока.

Для защиты хранимого содержимого мастер открывает **Файлы → Данные → Сохранить копию и включить защиту**. Перед переносом скачивается файл восстановления с ключом и снимком данных. Сохраните его вне Foundry Data. После записи и проверки зашифрованной копии старое поле состояния очищается. Новые сообщения, документы и изображения хранятся в зашифрованном контейнере AES-GCM.

Ключ находится только в браузере мастера и файле восстановления. Он не передаётся в настройках мира или через модульный сокет. При смене браузера/компьютера нужен импорт файла восстановления. Потеря и файла, и браузерного ключа делает зашифрованное содержимое недоступным. Включайте защиту через localhost или HTTPS. Игрокам не требуется WebCrypto или защищённый контекст для адресной переписки.

Прежние изображения, уже загруженные отдельными файлами, не удаляются при переносе и остаются доступными по старым URL. Защита также не отзывает ранее полученные копии и не изолирует данные от других модулей, работающих в браузере мастера. Несколько мастеров могут читать данные после импорта ключа; запись координируется основным подключённым мастером.

## Следующий этап — связь с Нетраннингом

Предлагаемый путь: **терминал → локальная точка доступа → существующая NET-архитектура → полученный файл → Агент → контакт**. Дистанция подключения, Интерфейс, NET-действия, ЛЁД и программы остаются в модуле Нетраннинга. Автоматический мост в этом обновлении не включён. Пока мастер выдаёт результат через документы Агента.

Новые возможности написаны для нашего модуля. Код и ресурсы CitiNET/Night City Messenger в это обновление не копировались.
