# Загрузка Агента у игрока

Агент получает доступные игроку данные от подключённого Мастера. Предупреждение «Мастер не ответил. Попробуйте ещё раз.» означает, что запрос не получил ответ за 20 секунд. Оно само по себе не определяет причину: нужно измерить ответ на конкретном столе.

## Изменения в 0.17.2

- Окно открывается со статусом подключения, пока данные загружаются. Ошибка видна в окне; кнопка «Повторить подключение» повторяет только чтение.
- Сохранённое действие подтверждается без ожидания остальных клиентов. Неудачная последующая загрузка не превращает сохранённую публикацию или файл в ошибку записи.
- Обновление настройки мира и уведомление о той же версии данных используют общий запрос. Подключение другого игрока не сбрасывает этот кеш.
- Обычное обновление сохраняет текущий экран и показывает статус синхронизации. При смене сцены, Мастера или прав доступа старые данные скрываются до проверки доступа. Формат хранилища и сохранённые вложения остаются прежними.

## Диагностика на проблемном столе

В окне загрузки выберите **«Диагностика связи»**. В загруженном Агенте эта команда находится в меню **⋯**. Команда **«Обновить данные и замер»** выполняет новый диагностический запрос. После его завершения откройте диагностику снова. Кнопка **«Копировать отчёт»** копирует технический отчёт. Он содержит версии, состояние связи и последние измерения; содержимое переписки, названия файлов, номера устройств и ключ восстановления в него не входят.

Для макроса доступна функция:

```js
game.modules.get('night-city-agent').api.connectionDiagnostics()
```

Поля `lastSnapshot` (последний запрос) и `lastMeasuredSnapshot` (последний успешный запрос с измерением размера):

| Поле | Значение |
| --- | --- |
| `ok` | Получен ли ответ |
| `roundTripMs` | Полное ожидание ответа в миллисекундах |
| `gmVersion` | Версия модуля у отвечающего Мастера |
| `initMs` | Подготовка хранилища на клиенте Мастера |
| `projectMs` | Отбор разрешённых игроку данных на клиенте Мастера |
| `bytes` | Размер JSON разрешённых данных до транспортного кодирования; измеряется при диагностическом запросе |

Если версия Мастера не поддерживает эти измерения, `gmVersion` равен `unknown`, а дополнительные поля отсутствуют. При тайм-ауте доступны `ok: false` и время ожидания. Значение `lastSnapshot: null` означает, что запрос ещё не завершён.

Большой размер ответа указывает на объём передаваемых данных. Большие `initMs` или `projectMs` показывают задержку обработки у Мастера. Если обработка быстрая, а полное ожидание большое, нужны дальнейшие измерения сети и активности вкладки Мастера. Каждый полный ответ всё ещё включает разрешённые вложения: их загрузку по запросу нужно оценивать по измеренному объёму конкретного мира.

Установите [версию 0.17.2](https://github.com/Defaulter444/night-city-agent/releases/tag/v0.17.2) на сервере Foundry. После обновления Мастеру и всем игрокам нужно полностью обновить страницу браузера (Ctrl+F5), чтобы оба клиента загрузили свежий код. Проверьте связь сначала на копии мира; [комплект отката к 0.17.1](ROLLBACK-RU.md) приложен к релизу.
