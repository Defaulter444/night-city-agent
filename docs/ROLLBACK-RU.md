# Откат Агента 0.17.2 к 0.17.1

В [релизе 0.17.2](https://github.com/Defaulter444/night-city-agent/releases/tag/v0.17.2) есть отдельный комплект отката. Исходный [релиз 0.17.1](https://github.com/Defaulter444/night-city-agent/releases/tag/v0.17.1) и его тег сохранены.

- [Архив для отката к 0.17.1](https://github.com/Defaulter444/night-city-agent/releases/download/v0.17.2/night-city-agent-rollback-0.17.1.zip).
- [Манифест с закреплённой версией 0.17.1](https://github.com/Defaulter444/night-city-agent/releases/download/v0.17.2/rollback-0.17.1.json).
- [Контрольные суммы SHA-256](https://github.com/Defaulter444/night-city-agent/releases/download/v0.17.2/SHA256SUMS.txt).

Манифест отката ссылается на этот же комплект, поэтому проверка обновлений не переведёт его обратно на новую версию. Обычный манифест Агента продолжает получать обновления.

## Как откатить установленный модуль

Эти действия выполняет человек с доступом к файлам сервера Foundry. Отключение модуля в запущенном мире не заменяет остановку сервера.

1. Сохраните резервную копию мира. Если защищённое хранилище включено, сохраните также ключ восстановления и экспорт данных через «Данные и резервные копии» Агента.
2. Полностью остановите Foundry VTT.
3. Перенесите текущую папку `Data/modules/night-city-agent` в резервную папку **вне `Data/modules`**. Оставьте её до завершения проверки отката. В ней могут быть ваши изменения компендиума модуля.
4. Создайте пустую папку `Data/modules/night-city-agent` и распакуйте туда архив отката. Файл `module.json` должен находиться непосредственно в этой папке.
5. Запустите Foundry. В разделе «Add-on Modules» проверьте, что у «Агент (Найт-Сити)» указана версия **0.17.1**. Запустите мир; Мастеру и всем игрокам нужно полностью обновить страницу браузера, например Ctrl+F5.

Для хостинга без доступа к файлам сервера используйте механизм установки конкретной версии, который предлагает ваш хостинг. Установка более старого манифеста поверх новой версии через обычный установщик Foundry отдельно не проверялась; приведённый здесь проверенный способ требует доступа к папке модуля.

Дополнительно можно выбрать **Lock Module** через правый щелчок по Агенту в разделе «Add-on Modules». Foundry не обновляет заблокированные модули. [Официальная инструкция Foundry](https://foundryvtt.com/article/modules/#locking-and-unlocking-modules).

## Что сохраняется

Откат меняет файлы модуля. Данные мира, устройства, переписки, публикации, места, файлы и ключ защищённого хранилища сохраняются: между 0.17.1 и 0.17.2 нет миграции их формата. Для этого отката не нужно восстанавливать старую копию мира поверх текущего — иначе новые игровые записи будут заменены данными из копии.

Комплект собран из опубликованного архива 0.17.1 с проверкой его SHA-256 и соответствия тегу `v0.17.1`. В манифесте изменены только ссылки на обновление и скачивание: они закреплены на комплекте отката. Все остальные файлы, включая карту и компендиум, совпадают с опубликованной 0.17.1.

Инструкция относится к откату **Агента 0.17.2 → 0.17.1**. Она не описывает понижение версии самого Foundry, игровой системы или других модулей. Для более раннего отката сохранена [инструкция 0.17.1 → 0.17.0](https://github.com/Defaulter444/night-city-agent/blob/v0.17.1/docs/ROLLBACK-RU.md).

## Как вернуться к обновлениям

При остановленном Foundry тем же способом установите обычный [архив 0.17.2](https://github.com/Defaulter444/night-city-agent/releases/download/v0.17.2/night-city-agent.zip): перенесите папку отката в резервную, распакуйте обычный архив в пустую папку модуля и перезапустите Foundry. Если включали Lock Module, снимите блокировку. Обычный архив использует манифест `releases/latest/download/module.json` и получает последующие обновления.
